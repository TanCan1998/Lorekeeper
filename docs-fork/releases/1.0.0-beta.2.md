# LoreKeeper 1.0.0-beta.2（预览版）

**这是预览版，非正式版，未完成全部原生验收。** 本版本继续使用 GitHub 普通 Release（prerelease=false），并显式设为 Latest；这不代表正式版质量或生产认证。`1.0.0-beta.1` 及其安装包保留，不删除、不覆盖。

## 本次调整（相对 beta.1）

- 新增 Windows 启动门禁：主程序检测应用包身份；无包身份时先尝试经身份激活器重启，失败才提示并退出。直接运行安装目录里的 exe 不再能绕过激活器拆分 WebView2 进程组。开发构建与 `--cleanup-project` 清理入口不受影响。
- 启动器错误日志从安装目录改到系统临时目录（`%TEMP%\LoreKeeper`），避免卸载后安装目录残留日志文件。
- 同步上游错误码可读文案、定稿后处理步骤说明与“忙转闲”刷新，失败面板不再只显示原始错误串。
- 本机补充验证（source 到本次构建之间）：MSI 1.0.1.0 的静默安装、修复安装、卸载；NSIS 静默安装与卸载；首次激活器注册/注销（Appx 1.0.1.0）；项目清理向导两次确认后只删除所选项目，其他项目与全局配置保留；无效项目清单会被拒绝。
- 云端：同一源码 SHA 的 Tauri Rust CI 全量与 `--all-targets` 通过。

## 已知限制

- 本次四个安装包尚未做原生安装/卸载/提权验收；上面的安装结论来自上一批产物，不能替代本次产物。
- 启动门禁的“自动拉起激活器”与失败提示只做了无窗口探针验证（退出码 42）与云端编译；真实安装后的交互行为待人工确认。
- 多用户 UAC、旧版本升级/回滚、macOS 真机安装与活动监视器归属仍未验收。
- Windows WebView2 进程归组依赖包身份；未经激活器启动的进程仍会拆组。Windows 未证书签名；macOS 仅 ad-hoc 签名，未公证。
- 真实模型、MCP、业务云与长期写作质量仍未认证。建议使用可丢弃项目和本地备份体验，不用于唯一正文副本。
