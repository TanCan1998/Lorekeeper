# Lorekeeper / 设定司 1.0.0-beta

首个公开预览版，面向本地长篇小说创作。本次发布为 **Tauri 2** 版，不是上游 Electron 安装包。

## 主要内容

- 纸墨流程界面：书房、设定、架构、蓝图、正文及运行侧页。
- 浅色/深色主题、字体与整页缩放；旧外观配置只读迁入新键。
- 本地项目、作者编辑、审稿/修稿/定稿流程与归档恢复。
- Lorekeeper独立数据目录：全局 `~/.lorekeeper`（或 `AI_NOVEL_LOREKEEPER_HOME`），项目 `.lore/`；不会自动读取上游Vela项目。
- 旧库导入、图片皮肤与旧外壳不提供；不自动连接MCP。
