# Lorekeeper / 设定司 1.0.0-beta

首个公开预览版，面向本地长篇小说创作。本次发布为 **Tauri 2** 版，不是上游 Electron 安装包。

## 主要内容

- 纸墨流程界面：书房、设定、架构、蓝图、正文及运行侧页。
- 浅色/深色主题、字体与整页缩放；旧外观配置只读迁入新键。
- 本地项目、作者编辑、审稿/修稿/定稿流程与归档恢复。
- Lorekeeper独立数据目录：全局 `~/.lorekeeper`（或 `AI_NOVEL_LOREKEEPER_HOME`），项目 `.lore/`；不会自动读取上游Vela项目。
- 旧库导入、图片皮肤与旧外壳不提供；不自动连接MCP。

## 下载选择

| 系统 | 安装包 |
| --- | --- |
| Windows x64 | `*-setup.exe`（NSIS）或 `*.msi`，二选一 |
| Apple Silicon | `*_aarch64.dmg` |
| Intel Mac | `*_x64.dmg` |

安装前建议备份项目。Windows需要WebView2运行时，缺少时安装器可能需要联网获取。MSI的内部数字版本为1.0.0.0，应用版本仍为1.0.0-beta；已有内部1.1.0安装可能拒绝降级，本次不承诺其自动降级或升级路径。

## 预览版限制

- **Windows未配置代码签名证书；macOS仅ad-hoc签名，未使用开发者证书且未公证**，可能被系统信誉或安全检查拦截。
- 三平台安装包由GitHub Actions构建；**尚未完成新包的真机安装与首次启动验收**。本机后台GUI验证不能替代安装验收。
- 真实模型、外部MCP及业务云服务尚未做发布级联网认证；相关能力依赖使用者自行配置，不承诺第三方服务可用性。
- 本次为预发布，不标记最新版，不承诺自动更新分发。

`SHA256SUMS.txt`、三平台原始打包清单与 `release-manifest.json` 随包提供。原始打包清单的 `published:false` 表示生成清单时尚未发布；发布状态以本Release及其API元数据为准。
