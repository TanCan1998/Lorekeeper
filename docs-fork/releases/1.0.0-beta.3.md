# LoreKeeper 1.0.0-beta.3（预览版）

> **已发布**（2026-10-25）。发布事实与验证记录见文末；流程见 `docs-fork/plans/2026-10-25-beta3-release-checklist.md`。
>
> 本版是**非正式版**预览构建：用于体验与反馈，不承诺数据格式稳定，也不代表完整原生验收。

## 本次调整（相对 beta.2）

**写作与检索**
- 模型名设置改成可输入的候选控件：输入即过滤、键盘可选；切换端点或配置后不再显示过期列表。
- 模型发现按用途筛选，并把「端点没有返回任何模型」与「端点返回的模型都不适合当前用途」分成两种明确提示；检索模型排在候选前面。
- 模型预设补充 Gemini 3 系列（含思考等级映射），已保存的旧预设继续可用。

**定稿与后处理**
- 重试按**当前**状态重算：旧版本遗留、现在流程已没有的步骤不再挡住重试，也不计入完成数；没有可重试步骤时直接说明，不再空跑一次。
- 提交期数据变化（角色状态被更晚章节写过、生成期间被改动等）给出可读说明，并明确「重试能否改变结果」。
- 同步上游错误码文案与后处理步骤说明，失败面板不再只显示原始错误串。

**界面与语言**
- 报错文案改为在**显示时**取界面语言：切换语言后，晚到的错误提示不会再串成另一种语言。
- 桌面图标重绘：星芒加大，并为 16–32px 单独提供简化版，任务栏与资源管理器里的小图标更清楚。

**安装与升级**
- 覆盖安装、卸载、重装、旧版升级（1.0.1.0 → 新版）均已本机验收：ARP 单条、快捷方式指向激活器、包身份按需注册。
- 安装与首次启动时不再闪 PowerShell 控制台窗口。
- **不支持降级安装**：回到旧版必须先卸载再装旧包（Windows 不允许 Appx 降级注册）。

**上游同步**
- 合并上游 1.3.2 与 2026-10-25 增量（151 提交），带来定稿后处理重试语义、reasoning policy、provider presets 与 verify 快照稳健性等修正。

## 已知限制

- 多用户 UAC（第二个登录账号下的提权注册）与 macOS 真机安装仍未验收。
- 不支持降级安装；降级会留下「文件已降、包身份未降」的不一致状态。
- NSIS 包为当前用户安装（`%LOCALAPPDATA%\LoreKeeper`），卸载后保留一份启动器诊断日志；MSI 与 NSIS 两套产品项独立，不要并存安装。
- Windows 未证书签名（首次运行会看到 SmartScreen 提示）；macOS 仅 ad-hoc 签名，未公证。
- WebView2 进程归组依赖包身份；直接运行 exe 会被启动门禁要求经激活器重启。
- 真实模型、MCP、业务云与长期写作质量仍未认证。建议使用可丢弃项目并保留备份，不要作为唯一正文副本。
