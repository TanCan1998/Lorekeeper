# 单任务派发与交付模板

每次派发填一份自包含简报；模型无需整读状态、历史快照和整个项目说明。

## 简报

- taskId / attempt / 批次 agent：
- 目标与明确不包含的工作：
- baseHead / 分支 / 已知工作区改动：
- 写面完整清单、已有占用与依赖 taskId：
- 读取入口：文件、符号、必要行区间；关键事实与契约：
- 当前任务适用红线：双栈/文档/数据/权限/依赖；禁止提交和修改状态：
- 模型通道、timeoutMs、检查点与研究/实现/自检预算：
- 验收命令、目录、通过条件及计数依据：
- 冲突/失败退出条件；新鲜 anchor、分支防护和增量检查：
- 结果与原始证据路径（由输出工具/扩展写入已授权位置）：

开工先用 contact_supervisor 自评并等待裁决。引用前先核对符号存在，不把历史行号当作当前事实。额外写面须退还编排者裁定。

## 交付

- taskId / attempt / runId / 执行结束状态：
- 实际改动文件与各文件作用：
- 验收命令 → exit → 原始证据路径 → 关键结果：
- 验证基准（HEAD + 相关工作区 diff/文件标识）：
- 与基线的差异、未完成项、阻塞和不确定点：
- 给下一任务的接口/符号与必要前置条件：

成功交付只意味着待复验。编排者独立复验后才标记已验证，记录 commit 后才标记已提交。重派使用同一 taskId 和新的 attempt，保留上一尝试链接。
