# Claude Design 美化版

用 Claude Design 画布制作的「纸墨」产品级美化方案，信息架构与 `../ia.md` 一致。

- 在线画布：https://claude.ai/artifact/VZDm5hKwmbvmhNwe7euujX （私有，仅作者可见）
- 本目录是画布中 7 块画板的源文件（`.dc.html`）与画布索引 `canvas.json`，只能在 Design 画布内渲染。

与 `../prototype/` 的差异：

- 外壳改为暖灰外框加悬浮圆角内容面板，层次靠阴影而不是分隔线。
- 流程脊每个阶段用进度环表示状态；章节号与阶段号改用 Instrument Serif 斜体数字。
- 顶栏加入 Ctrl K 搜索与跳转。
- 设定页简化为「一段核心大纲 + 三项必填」，其余设定收进标签按钮。
- 生成中的章节在纸面上实时出现正文，而不是空状态。
- 书房用排版封面展示作品，右侧是唯一主操作「继续写作」。
